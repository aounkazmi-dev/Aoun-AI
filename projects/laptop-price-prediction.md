# Laptop Price Prediction

**GitHub:** https://github.com/aounkazmi-dev/Laptop-price-prediction

## Summary

A regression project that predicts laptop prices using features such as brand, processor speed, RAM, storage, screen size, and weight.

## Reported workflow

- Data preprocessing
- One-hot encoding for categorical features
- Feature scaling
- Linear Regression model training
- Model evaluation
- Python, Pandas, Seaborn, and scikit-learn

The repository README reports R² of approximately 0.99. Treat this as a project-reported result, not a guarantee of real-world predictive accuracy. Before making a strong performance claim, check the train/test split, target leakage risks, baseline comparisons, and whether the metric was computed only on held-out data.

## What it demonstrates

A classical supervised-learning workflow, from tabular feature preparation to regression training and evaluation. It is a useful example of Aoun's ML foundations, distinct from his LLM application projects.
