# Career Direction and Development Goals

## Main goal

Build toward an **AI Engineer / Machine Learning Engineer** career, grounded in data science and ML fundamentals and extending into deep learning, NLP, generative AI, RAG, and agentic applications.

## Technical direction

1. **Data science:** data cleaning, exploratory analysis, statistics, visualization, SQL, and communicating findings clearly.
2. **Machine learning:** sound baselines, feature engineering, train/validation/test discipline, metrics, error analysis, and model selection.
3. **Deep learning and NLP:** build practical understanding of neural networks, sequence models, transformers, embeddings, and model evaluation through real implementations.
4. **AI engineering:** develop robust RAG and agentic systems, tool integrations, retrieval evaluation, observability, guardrails, latency/cost awareness, and useful failure handling.
5. **Software engineering:** strengthen APIs, testing, architecture, databases, deployment, security, and system design so AI projects can be maintained and used.

## Portfolio principle

Prefer projects that show a complete reasoning and engineering process: problem definition, data or document pipeline, baseline, implementation, evaluation, failure cases, interface, deployment, and documented limitations. Avoid presenting a list of libraries as a substitute for evidence.

## Near-term career intent

Aoun is pursuing opportunities to learn through internships and practical engineering roles. Teaching-assistant work has been discussed as a future possibility, but it should only be presented as experience after it is confirmed and underway.

## How AounOS should answer career questions

Frame Aoun as an ambitious student with tangible project evidence and a clear technical trajectory. Be confident about what he has built, honest about the difference between academic projects and production employment, and specific about the skills he is developing next.
