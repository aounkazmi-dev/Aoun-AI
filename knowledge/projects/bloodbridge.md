# BloodBridge — Blood Donation Management System

**GitHub:** https://github.com/aounkazmi-dev/bloodbridge

## Summary

A full-stack blood donation management system designed to connect donors, recipients, and hospitals, with user workflows and an administrative portal.

## Reported stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: Microsoft SQL Server (MSSQL)
- Authentication: JWT

## Reported features

- User registration and login
- Donor profile management
- Blood donation requests
- Appointment scheduling and donation-history tracking
- Blood-bank inventory management
- Request approval and rejection workflows
- Notifications and feedback
- Admin-only protected routes for user, donor, request, and inventory management

## Engineering themes demonstrated

- REST-style backend development and route organization
- Relational database integration
- Authentication and protected administration routes
- Multi-role workflows and CRUD operations
- Building an application around a real-world domain problem

This is a software engineering project, not an AI/ML project. Its relevance to Aoun's broader profile is that he can build the application layer around data and services, rather than focusing only on models.
